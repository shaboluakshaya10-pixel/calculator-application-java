# 🧮 Calculator Application

A simple and user-friendly **Calculator Application developed using Java**. The application performs basic arithmetic operations through a menu-driven console interface.

## 📌 Project Overview

The Calculator Application is a beginner-friendly Java project designed to demonstrate fundamental programming concepts such as variables, operators, conditional statements, loops, and switch-case statements.

Users can perform basic mathematical operations by selecting an option from the menu.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🚫 Division-by-zero handling
* 🔄 Multiple calculations without restarting
* 📋 Menu-driven interface
* 🚪 Exit option

## 🛠️ Technologies Used

* **Java**
* **Scanner Class**
* **Switch Case**
* **Do-While Loop**
* **Conditional Statements**
* **Arithmetic Operators**

## ⚙️ Requirements

To run this project, you need:

* Java JDK 8 or later
* VS Code, IntelliJ IDEA, or Eclipse
* Command Prompt / Terminal

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/calculator-application-java.git
```

### 2. Open the Project

Open the downloaded project folder in your preferred Java IDE.

### 3. Compile the Program

Open the terminal inside the project folder and run:

```bash
javac Main.java
```

### 4. Run the Program

```bash
java Main
```
